# 脑叶公司完整 EGO 镇压系统 v1.2.1

## 安装

在 AstrBot 插件页面或插件管理命令中使用仓库地址安装：

```text
https://github.com/taolicx/astrbot_plugin_lobotomy_corporation
```

插件只使用 AstrBot 自带 API 和 Python 标准库，不需要额外安装依赖。

## 数据迁移与存储

- 新版把运行数据保存在 AstrBot 的插件数据目录，不再把群组状态写进插件源码目录。
- 首次启动会将旧版插件目录中的 `data/*.json` 迁移到新的数据目录；首次安装则从 `data/defaults/` 初始化武器、护甲、饰品和异想体资料，员工及战斗状态为空。
- 仓库不包含员工名单、冷却、待救援或出逃状态。
- 从旧版更新前请先备份旧插件的 `data/`。若更新因本地 JSON 修改而被 Git 拒绝，更新后、首次启动前，将备份的 JSON 放回插件目录 `data/`，新版会自动迁移。

## 本次修复

- 修复伤害类型别名被一律按物理伤害结算的问题；不支持的类型会给出提示。
- 修复计数器参数和异想体录入参数不完整时抛异常的问题。
- 修复重复执行 `.出逃` 给已出逃异想体回血的问题。
- 镇压异想体时统一清理待结算状态并恢复逆卡巴拉计数器。
- 修复员工濒死后疯狂状态残留，以及删除已装备武器/护甲后资料查询报错的问题。
- JSON 数据采用原子写入；数据损坏时明确报错，不再悄悄按空数据覆盖。

## 立即镇压异想体

- `.镇压 异想体名`：立即镇压指定的出逃异想体，将其重新收容并恢复逆卡巴拉计数器。
- 镇压时会清除该异想体相关的待释放攻击、攻击冷却和待闪避伤害。

示例：

```text
.镇压 西里安
```

## 彻底杀死员工

- `.彻底杀死 员工名`：立即将指定员工标记为永久死亡，无法再通过救援复活。
- 员工死亡后会清除其待闪避伤害、攻击冷却和待释放攻击。

示例：

```text
.彻底杀死 玛蒂尔达
```

## 员工互殴

- `.员工互殴 攻击者名 对 目标名 进行 Y次攻击，此攻击加成为 X`
- 正常员工和疯狂员工都可使用，不要求任何一方先进入疯狂状态。
- 目标生命值归零后会进入濒死状态，仍可在救援期限内救援。

## 疯狂系统

- `.陷入疯狂 员工名`：使员工陷入疯狂状态。
- `.解除疯狂 员工名`：手动解除疯狂状态。
- `.攻击疯狂 攻击者名 对 目标名 进行 Y次攻击，此攻击加成为 X`：只要攻击双方中有一方处于疯狂状态即可使用。

### 对疯狂员工的伤害规则

| 武器类型 | 效果 |
|----------|------|
| 精神 | 只扣疯狂值 |
| 侵蚀 | 同时扣生命值和疯狂值 |
| 物理/灵魂 | 只扣生命值 |

疯狂值归零时自动解除疯狂状态，生命值归零时进入濒死状态。

## 相关基础指令

- `.出逃 异想体名`：使指定异想体突破收容。
- `.进行攻击 员工名 对 异想体名 进行 Y次攻击，此攻击加成为 X`：员工攻击出逃异想体。
- `.异想攻击 异想体名 对 员工名 进行 Y次攻击，此攻击加成为 X`：出逃异想体攻击员工。
- `.异想体互殴 异想体A 对 异想体B 进行 Y次攻击，此攻击加成为 X`：两个出逃异想体互相攻击。
- `.死亡名单`：查看已经永久死亡的员工。
- `.移除死亡 员工名`：从员工数据中移除已经永久死亡的员工。

冷却中的攻击会先存入堆栈，并在冷却结束后的下一次对同一目标攻击时一并结算。
