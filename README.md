# 脑叶公司完整EGO镇压系统 v1.1.0

## 新增功能

### 疯狂系统
- `/陷入疯狂 员工名` - 使员工陷入疯狂状态
- `/解除疯狂 员工名` - 手动解除疯狂状态

### 员工互相攻击
- `/攻击 攻击者名 目标名 次数` - 统一攻击指令，支持员工打员工

### 疯狂状态机制
| 武器类型 | 对疯狂员工的效果 |
|----------|------------------|
| 精神 | 只扣疯狂值 |
| 侵蚀 | 同时扣生命值和疯狂值 |
| 物理/灵魂 | 只扣生命值 |

疯狂值归零时自动解除疯狂状态，生命值归零时进入濒死。

## 指令变更
- 所有指令前缀从 `.` 改为 `/`
- 评级使用全称：HE/WAW/ALEPH
